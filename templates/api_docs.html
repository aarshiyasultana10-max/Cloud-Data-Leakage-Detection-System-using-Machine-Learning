API Documentation

DLP Shield REST API — integrate DLP scanning into any application

POST /api/scan

Scan text for data leaks using rule-based patterns + ML classification + NER. Returns risk score and detected patterns.

Request Body
{
  "text": "My email is test@example.com and aadhaar is 1234 5678 9012"
}
Response (200 OK)
{
  "status": "leak",
  "rules": ["Email", "Aadhaar"],
  "ml_prediction": "leak",
  "confidence": 91.4,
  "risk_score": 55,
  "ner_entities": ["test [ORG]"]
}
cURL Example
curl -X POST http://localhost:5000/api/scan \
  -H "Content-Type: application/json" \
  -d '{"text": "password=admin123 email user@corp.com"}'
GET /api/stats

Returns live system statistics — total scans, leaks detected, safe files, security events, and quarantine count.

Response (200 OK)
{
  "total": 42,
  "leaks": 15,
  "safe": 27,
  "attacks": 8,
  "quarantined": 15
}
